# Muse Cat

A baby Siamese cat avatar built with [open-bot-avatar](https://github.com/DominikScholz/open-bot-avatar) — a JSON spec and renderer for interactive agent avatars.

- Interactive preview: https://c00lpeace.github.io/muse-cat/
- Avatar definition: [muse-cat.json](muse-cat.json) (passed strict validation, face clearance 13.4)
- Default look: Siamese cream body `#E9C9A8` with blue eyes `#2F5D8A`

The avatar's eyes follow your pointer, and its mood (idle / thinking / happy) and fur color can be switched on the preview page.
